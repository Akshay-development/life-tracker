# 🌟 Life Tracker

A modern, mobile-friendly web application to track daily habits, health routines, fitness, and personal progress.

## Features

- 🌅 Wake Up Tracker
- 💧 Water Intake
- 💪 Gym Tracker
- 🚿 Hair Wash Schedule
- 🌞 Minoxidil AM
- 🌙 Minoxidil PM
- 💊 Medicine AM
- 💊 Medicine PM
- 📊 Dashboard & Streaks
- ☁️ Google Sheets Integration
- 📱 Mobile Responsive
- 🌙 Dark Mode (Coming Soon)

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Apps Script
- Google Sheets
- GitHub
